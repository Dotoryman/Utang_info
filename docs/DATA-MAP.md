# UtangLand 데이터 구조와 삭제 범위

## D1

| 데이터 | 주요 내용 | 삭제 시점 |
|---|---|---|
| users | 이메일, 닉네임, 비밀번호 해시, 역할, 프로필 이미지 키 | 회원 탈퇴 또는 관리자 주민 삭제 |
| sessions | 로그인 세션의 해시와 만료 시각 | 로그아웃, 비밀번호 변경, 탈퇴, 주민 삭제 |
| posts | 광장 게시글 | 작성자 탈퇴·삭제 또는 게시글 삭제 |
| comments | 광장 댓글 | 작성자 탈퇴·삭제, 게시글 삭제 또는 댓글 삭제 |
| post_likes | 게시글 좋아요 | 사용자·게시글 삭제 |
| notifications | 댓글·좋아요 알림 | 사용자·게시글 삭제 또는 읽은 알림 정리 |

비밀번호 원문과 로그인 세션 원문은 D1에 저장하지 않습니다.

## R2

`utangland-profile-images` 버킷에는 주민이 올린 프로필 이미지만 저장합니다.
이미지 키는 D1의 `users.profile_image`가 참조합니다.

- 새 이미지 등록 시 이전 이미지를 삭제합니다.
- 프로필 이미지 제거 시 해당 객체를 삭제합니다.
- 회원 탈퇴와 관리자 주민 삭제 시 연결된 객체를 삭제합니다.
- 업로드 한도와 전체 버킷 한도를 애플리케이션에서 함께 검사합니다.

## 브라우저 저장소

우땅점술소의 당일 운세 결과는 기기별 편의를 위해 브라우저 저장소에
보관합니다. 계정의 공식 기록이나 서버 데이터로 사용하지 않습니다.
